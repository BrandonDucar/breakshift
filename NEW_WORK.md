# Submission Boundary

This package extracts the event-built BREAKSHIFT workcell, not the pre-existing
DreamNet platform or Change Witness application. The owner-provided event window
is October 26 through November 4, 2026. Final eligibility requires the accepted
official rules, contributor identification and dated development evidence.

## Included Project Work

- Worker media intake, component inspection and recorded model diagnosis.
- Repair-plan compilation, simulated workcell replay and fault experiments.
- Uncertainty-envelope checks, stale-result rejection and receipt replay.
- Independent tests and the offline energy comparison module.
- Original fictional-machine illustrations and locally encoded synthetic clip.

## Existing External Material

The vendored Meta SAM parser keeps its own LICENSE. Node.js, browsers, Cloudflare
and Meta APIs are external platforms, not team-authored inventions. Referenced
manufacturer catalog entries are references only, not qualified hardware adapters.
Recorded model output is evidence of a historical proposal, not code ownership
or a current provider execution claim.

## Remaining Submission Gates

Owner review of this exact source/fixture allowlist, independent reviewer sign-off,
public repository publication, contribution dates/credits and a three-minute demo
remain separate gates. A local snapshot commit made by the packaging verifier is
an extraction checkpoint, not evidence of when each original feature was authored.
